¿Qué es este proyecto?

VectorBank es una aplicación web fullstack que simula la banca en línea: permite gestionar cuentas, realizar depósitos y consultar movimientos desde una interfaz construida en Angular, consumiendo una API REST en Node.js/Express con persistencia en MongoDB. El objetivo fue poner en práctica el flujo completo de una operación financiera cuidando la validación de datos y la seguridad en el backend.

Módulos del sistema

El sistema cubre las operaciones y vistas principales de un banco digital:

Autenticación Login con contraseña y con huella (biometría)
Recuperación de contraseña Restablecimiento seguro de credenciales
Dashboard Resumen de cuentas, saldos y actividad
Depósitos y transferencias Movimientos entre cuentas con validaciones
Historial de transacciones Consulta detallada de todos los movimientos
Perfil Datos y configuración del usuario
Notificaciones Avisos de actividad de la cuenta
Modo oscuro Tema claro/oscuro en toda la interfaz
Panel de administración Gestión de cuentas y usuarios

Lo que aprendí

Este proyecto me permitió trabajar el ciclo completo de una operación financiera, reforzando la validación de datos y la seguridad en el backend. Profundicé en Angular —componentes, servicios, guards de rutas e interceptores para adjuntar el token JWT— y en el diseño de una API REST con Express y MongoDB mediante Mongoose. También implementé autenticación con contraseñas cifradas, inicio de sesión con huella y un flujo seguro de recuperación de contraseña.
