¿Qué es este proyecto?

Sistema de escritorio desarrollado para la CFE, orientado a administrar la impartición de cursos de capacitación según las distintas zonas donde se llevan a cabo. Al ser una aplicación local, el sistema centraliza la información sin depender de una conexión externa, facilitando su uso dentro de la institución.

Función principal

El sistema gestiona el registro, organización y consulta de cursos asignados a cada zona de implementación, permitiendo tener un control claro de qué se está impartiendo y en dónde. Toda la información se almacena de forma local mediante una base de datos MariaDB, lo que mantiene la aplicación funcionando de manera independiente.
