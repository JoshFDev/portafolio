¿Qué es este proyecto?

NexoraLabs es una plataforma web fullstack que conecta a estudiantes y personas en formación con proyectos reales, recursos de aprendizaje y oportunidades. Los usuarios pueden crear o explorar proyectos, formar equipos, declarar sus habilidades, acumular logros y postularse a ofertas de empleo o prácticas. El frontend está construido con React y Vite, y consume una API REST en Node.js/Express con persistencia en MongoDB. Todo el proyecto se puede levantar con contenedores mediante Docker Compose.

Módulos del sistema

La plataforma cubre todo el recorrido de una persona en formación, desde su perfil hasta su primera oportunidad:

Usuarios y perfiles Registro, login, edición con foto (recorte al subir), perfil público, habilidades e intereses
Proyectos Creación con roles válidos, exploración con filtros, postulaciones y comentarios
Equipos Creación (admin o mentor), solicitudes de ingreso, miembros y roles
Recursos de aprendizaje Catálogo con búsqueda, filtros y calificaciones
Ofertas de empleo Publicación, búsqueda, modalidad y postulación
Logros Desbloqueo automático según la actividad del usuario
Notificaciones Avisos de actividad con ajustes personalizables
Roles y permisos Admin, mentor, desarrollador, ingeniero y estudiante con permisos distintos por módulo
Dashboard de administración Estadísticas y gestión general de la plataforma

Stack tecnológico

⚛ React 19 + Vite Frontend SPA
BS React-Bootstrap Componentes e interfaz (Bootstrap 5)
RR React Router + Axios Navegación y cliente HTTP con manejo de token
JS Node.js Entorno de ejecución backend
EX Express Framework — API REST
DB MongoDB + Mongoose Base de datos NoSQL y modelado
JWT JSON Web Token Autenticación por token
🛡 Helmet, CORS, rate-limit Seguridad de la API
🧪 Jest, Supertest, Vitest Pruebas de API y de componentes
🐳 Docker + NGINX Contenedores, Docker Compose y servidor del frontend
CI GitHub Actions Integración continua con ESLint y Prettier

Lo que aprendí

Con NexoraLabs trabajé una aplicación de mayor escala, con múltiples módulos y permisos por rol: middlewares para verificar el token y autorizar cada acción, validación de datos y una API protegida con Helmet, CORS y límite de peticiones. En el frontend profundicé en React 19 y Vite, con rutas, componentes reutilizables y un cliente Axios que gestiona el token. También aprendí a escribir pruebas automatizadas con Jest, Supertest y Vitest contra una base de datos separada, a mantener la calidad del código con ESLint y Prettier en CI, y a dockerizar todo el proyecto con Docker Compose, un build multi-stage para el frontend servido por NGINX y la opción de elegir entre MongoDB Atlas o un contenedor local.
