01 — sobre mí

Backend developer con visión de punta a punta

Soy estudiante de Ingeniería en Computación enfocado en el desarrollo backend. He construido sistemas web y de escritorio para instituciones como la Escuela Militar de Transmisiones y la Comisión Federal de Electricidad, además de desarrollos colaborativos académicos y sistemas para clientes reales.

Mi meta es convertirme en un backend developer sólido, escribiendo código que sea mantenible, entendible y que resuelva problemas reales.

  • Trabajando con Java, C# y JavaScript/TypeScript del lado del servidor
  • APIs REST con Spring Boot, Node.js + Express y .NET
  • Ecosistema Java: Spring y JavaServer Faces (JSF)
  • Frontend con React, Next.js, Angular y Bootstrap para consumir servicios de punta a punta
  • Profundizando en bases de datos relacionales y no relacionales
